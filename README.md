# 🎬 Movie Explorer

Movie Explorer is a responsive, modern web application built with React and Tailwind CSS. Users can discover popular TV shows, search for specific movies dynamically, and view detailed information in an interactive modal.

---

## 🌐 Live Demo & Links

- **Live Demo:** (https://movie-explorer-blush-eta.vercel.app/)
- **GitHub Repository:** (https://github.com/ShohagBasak/MovieExplorer.git)

---

## ✨ Features

- **Hero Banner:** Eye-catching cinematic hero section with CTA navigation.
- **Dynamic Search:** Real-time search functionality querying the TVMaze API.
- **Interactive Details Modal:** Clicking "See Details" opens an interactive modal with show synopsis, ratings, premiered date, and genres.
- **Empty / Error States:** User-friendly messages when no search results are found.
- **Fully Responsive:** Optimized for Mobile, Tablet, and Desktop screens using responsive Grid layouts.
- **Modern UI:** Built with DaisyUI & Tailwind CSS using dark-mode cinema aesthetic.
